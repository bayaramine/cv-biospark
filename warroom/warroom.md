**Q&A prep — likely interview questions:**

| Question | Key talking points |
|----------|-------------------|
| What was MARIPOSA-2 trying to show? | Post-osimertinib NSCLC had no targeted options; chemo median PFS ~4.4 months historically. MARIPOSA-2 tested whether EGFR-MET bispecific (amivantamab) ± TKI (lazertinib) added to chemo could meaningfully extend PFS. Dual primary endpoints (two independent comparisons vs chemo). |
| What were the main findings? | Both AC and ALC significantly improved PFS: HR 0.48 and 0.44; medians 6.3 and 8.3 vs 4.2 months. ORR doubled (~64% vs 36%). Intracranial PFS also improved. OS data immature at primary analysis. |
| What was the statistical complexity? | Dual primary endpoints requiring multiplicity control via graphical approach with α-recycling from PFS → ORR → OS. Mid-study protocol amendment for ALC regimen (lazertinib deferral) to mitigate hematologic toxicity — required careful definition of analysis sets. VTE monitoring and mitigation (prophylactic anticoagulation) in ALC arm. |

## BOIN DESIGN

### What it is
Bayesian Optimal Interval design for Phase I dose-escalation. Determines dose escalation/de-escalation decisions based on pre-specified toxicity intervals.

### When to use it
Phase I oncology trials where the goal is to find the Maximum Tolerated Dose (MTD).

### How I applied it
- ramantamig Phase Ib at J&J — BOIN design specification and simulation

### Regulatory context
- Accepted by FDA and EMA for Phase I oncology
- FDA guidance on model-assisted designs (2019)

### Packages / software used
- `BOIN` R package

### Common questions / misconceptions
- Q: What's the difference between BOIN and 3+3?
- Q: How do you set the target toxicity rate?

---

## BLRM (BAYESIAN LOGISTIC REGRESSION MODEL)

### What it is
Bayesian dose-escalation model using a two-parameter logistic regression with prior distributions. Used for dose-finding with EWOC (Escalation With Overdose Control) criterion.

### When to use it
Phase I and adult-to-pediatric bridging studies where Bayesian updating of dose-toxicity relationship is needed.

### How I applied it
- Asciminib pediatric bridging study at Novartis — prior calibration and dose-escalation simulation using OncoBayes2

### Regulatory context
- EMA and FDA accepted
- PIP/iPSP pediatric programs
- ICH E9 Bayesian framework

### Packages / software used
- `OncoBayes2` R package

---

### What it is
Designs allowing for early stopping of trials for efficacy or futility based on interim analysis data.

## ESTIMAND FRAMEWORK (ICH E9(R1))

### What it is
A framework for defining the treatment effect that is to be estimated in a clinical trial, aligning the trial's objective with its design and analysis.
