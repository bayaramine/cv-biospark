## BOIN DESIGN

### What it is
Bayesian Optimal Interval design for Phase I dose-escalation. Determines dose escalation/de-escalation decisions based on pre-specified toxicity intervals.

### When to use it

## BLRM (BAYESIAN LOGISTIC REGRESSION MODEL)

### What it is
Bayesian dose-escalation model using a two-parameter logistic regression with prior distributions. Used for dose-finding with EWOC (Escalation With Overdose Control) criterion.

### When to use it
Phase I and adult-to-pediatric bridging studies where Bayesian updating of dose-toxicity relationship is needed.

### How I applied it
- Asciminib pediatric bridging study at Novartis — prior calibration and dose-escalation simulation using OncoBayes2

### Regulatory context
- EMA and FDA accepted
- PIP/iPSP pediatric programs
- ICH E9 Bayesian framework

### Packages / software used
- `OncoBayes2` R package
